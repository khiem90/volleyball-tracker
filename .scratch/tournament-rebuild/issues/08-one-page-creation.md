# 08: One-page creation

**What to build:** Creating a tournament is one page: pick a format, name it, tick roster teams or
add new ones inline, expand advanced settings only if needed, then "Save as
draft" or "Create and start". Both land on the console. The three-step wizard is
removed.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] A tournament can be created and started in six taps or fewer from the Tournaments tab.
- [ ] Teams added inline are saved to the roster and ticked.
- [ ] Advanced settings (courts, series length, instant win, scoring, terminology) stay hidden until expanded and persist on the tournament.
- [ ] Validation rejects an empty name and fewer teams than the format needs, with the reason shown.
- [ ] The old wizard and its step components are deleted.
